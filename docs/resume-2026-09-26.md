## 6. Rebuilding the tooling after the container restarts

The lanes and their scripts are in `scripts/e2e-lanes/`; `docs/video2-resume.md` §5 covers rebuilding the environment. Lane N means API `:302N` and database `rundesk_vN`.
- `build-api.sh "2 3 4 5"` after any API edit, test files included, because `verify.sh` refuses a stale build.
- `refresh-dists.sh "2 3 4 5"` after any web edit.
- `verify.sh <suite> <lane>` writes `/tmp/claude-0/run-<suite>.log`.
- `sweep.sh "<lanes>" suites…` writes `/tmp/claude-0/sweep-status.txt`.
- `RUNDESK_LANE_MODEL=2 bash scripts/e2e-lanes/fleet-restart.sh 2` gives lane 2 the model stub.

Three helpers lived only in `/tmp` and are kept here.

**The lane-1 break runner** (`/tmp/claude-0/run-sets-lane1.sh <plan>`; each plan line is `suite patch…`):

```bash
#!/bin/bash
# Run break sets one after another on lane 1; a set refused because its suite is busy elsewhere is retried.
cd /home/user/rundesk
while IFS= read -r line; do
  [ -z "$line" ] && continue
  set -- $line
  for attempt in $(seq 1 40); do
    bash scripts/e2e-lanes/wt-break.sh 1 "$@" > /tmp/claude-0/wt-break-lane1-$1.log 2>&1
    rc=$?
    if [ $rc -ne 3 ]; then echo "$(date +%H:%M:%S) $1 exit $rc"; break; fi
    echo "$(date +%H:%M:%S) $1 busy, retrying"; sleep 60
  done
done < "$1"
echo "ALL DONE"
```

Reports land in `/tmp/claude-0/break-<suite>-<time>.txt`. Never edit a running script in place: write a new file and move it over.

**Checking a patch compiles before queueing it** (`compile-patches.sh <api|web> <patch.py>…`). It needs a scratch worktree, `git worktree add --detach /tmp/claude-0/wtc HEAD`, with each `node_modules` of the main tree symlinked into the same place. It copies the working tree's uncommitted files in, type-checks a baseline, then applies each patch alone, type-checks, and restores:

```bash
#!/bin/bash
set -u
KIND="$1"; shift
MAIN=/home/user/rundesk
WTC=/tmp/claude-0/wtc
cd "$WTC" || exit 1
git checkout -q -f --detach "$(git -C "$MAIN" rev-parse HEAD)" || exit 1
{ git -C "$MAIN" diff --name-only HEAD; git -C "$MAIN" ls-files --others --exclude-standard; } | sort -u | while read -r f; do
  case "$f" in node_modules/*|*/node_modules/*) continue ;; esac
  if [ -f "$MAIN/$f" ]; then mkdir -p "$(dirname "$WTC/$f")"; cp "$MAIN/$f" "$WTC/$f"; else rm -f "$WTC/$f"; fi
done
tc() { (cd "$WTC/apps/$KIND" && timeout 900 pnpm exec tsc --noEmit -p tsconfig.json 2>&1 | grep -E "error TS" | head -5); }
base=$(tc)
if [ -n "$base" ]; then echo "== BASELINE DOES NOT COMPILE"; echo "$base"; exit 1; fi
echo "== baseline compiles"
for p in "$@"; do
  name=$(basename "$p" .py)
  sed "s#/home/user/rundesk/#$WTC/#g" "$p" > /tmp/claude-0/wtc-patch.py
  files=$(grep -oE "^p *= *['\"][^'\"]+['\"]" /tmp/claude-0/wtc-patch.py | sed -E "s/^p *= *['\"]//; s/['\"]$//" | sort -u)
  for f in $files; do cp "$f" "$f.bak"; done
  if python3 /tmp/claude-0/wtc-patch.py > /dev/null 2>/tmp/claude-0/wtc-pf.err; then
    out=$(tc)
    if [ -z "$out" ]; then echo "== $name compiles"; else echo "== $name DOES NOT COMPILE"; echo "$out"; fi
  else
    echo "== $name PATCH FAILED: $(tail -1 /tmp/claude-0/wtc-pf.err)"
  fi
  for f in $files; do mv "$f.bak" "$f"; done
done
```

**Reading a break report against its claims** (`verdicts.sh <suite> <report> [patch…]`). The repo's own gate is `scripts/check-break-reddened.mjs`, which the preflight runs. This quicker reader takes escaped quotes (`\"`) in a claim as quotes, and reads only a claim's first line:

```bash
#!/bin/bash
suite="$1"; R="$2"; shift 2
pats="$*"; [ -z "$pats" ] && pats=$(grep -l "Reddens: $suite:" test/e2e/breaks/*.py | xargs -n1 basename | sed 's/\.py$//' | sort -V)
for n in $pats; do
  p="test/e2e/breaks/$n.py"
  claims=$(python3 - "$p" "$suite" <<'PY'
import re, sys
p, suite = sys.argv[1], sys.argv[2]
for line in open(p, encoding='utf-8'):
    m = re.match(r'^#( Reddens: ' + re.escape(suite) + r':|   or) "((?:[^"\\]|\\.)*)"', line)
    if m:
        print(m.group(2).replace('\\"', '"'))
PY
)
  sec=$(awk -v n="== $n" '$0 ~ "^== "{on = (index($0, n) == 1)} on' "$R")
  hit=0
  while IFS= read -r c; do [ -n "$c" ] && echo "$sec" | grep -F "FAIL $c" > /dev/null && hit=1; done <<< "$claims"
  if [ -z "$sec" ]; then echo "$n: no section"; elif [ $hit = 1 ]; then echo "$n: reddened"; else echo "$n: NOT reddened — $(echo "$sec" | tail -1)"; fi
done
```

**The preflight:** `bash scripts/preflight.sh > /tmp/claude-0/preflight-full.log 2>&1`. Read every step with `awk '/^=== /{h=$0} /^    (OK|FAILED)$/{print $0 " | " h}'`. These steps fail in known ways while work is under way, and each must be read to confirm that is all they say:
- "break runs measured this tree": sets not yet re-run on a moved tree;
- "and reddened the one they name": patches with no run log yet;
- "and the unit claims redden too": fails only on an uncommitted tree.
