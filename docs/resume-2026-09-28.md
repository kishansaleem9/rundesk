## 3a. CI on 1 October, and how to push from now on

The month's Actions minutes came back on 1 October. The repository is
private, so CI minutes are billed; September's ran out on the 21st, and no
run had reached the Postgres suites since 10 September (56 suites then, 256
now). The first run, on `7e21f3f`, failed Verify at step 57 on a path to
this machine's checkout (`found-1-oct/sweep-selfcheck-names-this-machines-checkout`).

So every job was rehearsed here before anything else went out, with
`scripts/ci-rehearsal/` (its README says what it copies from the runner and
what it cannot). It found, beside that one: the clip page's "Loading the
clip…" (`loading-states`), a stale planted row in the calls harness, and
a planner bug that shows only on the 1st of a month
(`found-1-oct/planner-blocks-keyed-on-their-first-day`). All are closed in
the ledger. Its own false alarms are noted in the README too: a browser with
only loopback reports itself offline.

**The owner's decisions on CI, 1 October:**
- Push after every 20 closed items, not after each batch: every push is a
  full run of about an hour and a quarter (the Postgres suites took 101
  minutes here on two CPUs; the runner is about 2.4 times faster).
- CI stops at its first failure (7a68a48): no step runs after a failure,
  each Postgres-job step is capped at 15 minutes, and the Postgres job waits
  for Verify and Browser suites.
- So before a push: `bash scripts/ci-rehearsal/all.sh` (about two hours
  here), and push only when every job's every step passed.

## 5. Things learned today worth keeping

- The container can restart mid-run: every lane, runner and Postgres dies.
  `fleet-restart.sh "1 2 3 4 5 6 7"` (with `RUNDESK_LANE_MODEL=2`) brings them
  back; re-queue break sets from their report files (a finished set ends in
  `DONE <suite>`).
- Run the FULL preflight before a commit, not single gates: 8e398c1 broke
  `check-model-lanes.sh`'s mutation 5, which only the full preflight showed.
- Check a staged commit on its own (`git checkout-index -a --prefix=…`) —
